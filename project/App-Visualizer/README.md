# App Visualizer

Marketing "device mockup" images generated from the clean app captures in
`App-Screenshots-{English,Arabic,Turkish}/`. Each screenshot is composed into
an on-brand Papkram frame — playful/bold system: cream/purple/orange/yellow
saturated backgrounds, dotted texture, hard 3px borders, hard-offset shadows,
a rotated sticker eyebrow, and a Bricolage Grotesque headline (Cairo for
Arabic). All exported at 2× (2880px wide).

- **Phone screens** sit in a dark rounded bezel with a dynamic-island status
  bar. The full screen is shown, so tall pages become long-scroll mockups.
- **Landing pages** sit in a browser window frame (traffic lights + `papkram.de`).
- **Arabic** renders right-to-left, including a mirrored status bar.
