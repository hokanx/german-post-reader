Papkram — UI & App Visual Sheetv1.0 · Product Design System
Dread → Clarity → Action

Every screen moves one letter from dread to done.

The interface is the methodology made visible. Four steps — Upload, Understand, Deadline, Reply — each a screen, each a step of the DECODE Protocol. Warm surfaces, one loud action, and the answer always in violet.

01 — Interface principles

Calm surface, single action

Reduce cognitive load at every step. The user is anxious; the screen should feel like a steady hand.

SURFACE

Warm, not clinical

Papier-cream backgrounds and rounded cards. Never a cold white bureaucratic form.

ONE ACTION

One amber button

Exactly one primary action per screen, always in Frist-Amber. Everything else recedes.

THE ANSWER

Violet = clarity

Whatever decodes the letter — meaning, the reply — is marked in violet.

URGENCY

Red is earned

Red only for real deadlines and warnings. If everything is urgent, nothing is.

STATUS SYSTEM

Open · Replied · Overdue

Amber “Open” = action needed, green “Done” = replied, red “Overdue” = past Frist. Colour carries the state at a glance.

EMPTY STATE

An invitation, not a void

“No letters yet — upload the one on your table and watch the dread disappear.” One amber button beneath.

SEARCH

Find any past letter

Search by sender, date or keyword. The follow-up letter arrives with full context intact.

08 — Motion & states

Movement that reassures

Motion should feel like a breath out, not a flourish. Respect reduced-motion; nothing blinks or races.

DECODE

Blur → sharp

On analysis, German text de-blurs into the plain-language summary. The core brand gesture.

PROGRESS

Amber dot travels

The 4-step dots advance one screen at a time — visible momentum through the flow.

SUCCESS

Reply settles in

The German reply eases up with a soft check. Calm, not confetti.

PRESS

Shadow collapses

Buttons push their 6px hard shadow to 0 on tap. Tactile, physical, honest.
